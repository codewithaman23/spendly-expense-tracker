# 💰 Spendly — Expense Tracker

Spendly is a simple expense tracker that I built using **HTML, CSS, and JavaScript**.

I created this project to practice JavaScript by building a small and useful web application instead of only working on separate coding exercises.

Spendly allows users to enter their expenses, view them on the page, and keep track of their total spending.

---

## ✨ Features

* Add a new expense
* Enter expense name, amount, category, and date
* Form validation
* Display expenses dynamically
* Calculate total expenses
* Reset the form after adding an expense
* Responsive design
* Smooth CSS animations
* Clean and easy-to-use interface

---

## 🛠️ Technologies Used

* **HTML5** — Used to create the structure of the application
* **CSS3** — Used for styling, responsive design, and animations
* **JavaScript** — Used for DOM manipulation, events, form validation, arrays, objects, and calculations

---

## ✨ Animations

I added some simple CSS animations and transitions to make the interface feel more interactive without making it too distracting.

* Page load animation
* Expense card appearance animation
* Card hover effects
* Input focus effects
* Button hover animation
* Button click effect
* Smooth transitions throughout the interface

The animations are kept simple so the application remains clean and easy to use.

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding your expenses.

You can also use the **Live Server** extension in VS Code to run the project locally.

---

## 💡 Project Highlights

One of the main things I focused on while building Spendly was understanding the connection between **HTML and JavaScript**.

For example, when a user submits the form, JavaScript takes the entered information, validates it, creates an expense object, stores it in an array, and then displays the expense on the webpage using DOM manipulation.

I also used CSS transitions and animations to make the interface more interactive and give the project a smoother feel.

The project is simple, but it gave me practical experience with the JavaScript concepts I had been learning.
